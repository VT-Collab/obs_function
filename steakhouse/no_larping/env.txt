

Modified Steakhouse env

Dispencers
1. meat, onion, and plate dispencers only dispense if player empty handed -> player now holds that item

Stations:
1. Pot
    a. if not cooking: accepts a player only holding meat, and starts cooking without humans physically there -> takes
        raw meat from their hands 
    b. if cooking: no interaction allowed
    c. if ready: only accepts a player with washed_plate or garnish_dish in hand (NOT just plate), at which point 
        the human will hold either a steak_dish or dish  
2. sink
    a. if not washing: accepts a player only holding plate (not washed plate), and the plate will be taken off human's hands
        human needs to physically there to wash it. They can leave midway washing, but the washing timer will stop (player can resume
        where it left off at a later time)
    b. if washing: human is standing in front, washing it
    c. if ready: when the washing timer is done, the sink is ready to dispence a washed_plate
        i. empty handed player or a player holding garnish can pick the washed_plate up and now either holding washed_plate
        or garnish_dish
3. board
    a. if not chopping: accepts a player only holding onion, and the onion will be taken off human's hands 
        human needs to physically there to chop it. They can leave midway chopping, but the chopping timer will stop (player can resume
        where it left off at a later time)
    b. if chopping: human is standing in front, chopping it
    c. if ready: when the chopping timer is done, the white onion now becomes green colord garnish
        i. empty handed player or a player with a WASHED plate (not just plate) or steak_dish can pick it up and now they either
            hold the garnish or garnish_dish or dish depending on if they had the washed plate or steak_dish

4. delivery site 
    a. only accepts player holding dish, and then advances delivery count

5. counter
    a. if empty:
        i. a player holding all of the: meat, onion, plate, washed_plate, garnish, garnish_dish, steak_dish, or dish can drop it freely off on the counter directly in front of them

    b. if not empty:
        i. meat, onion, plate, dish
            1. only player holding nothing can pick up all of the above depending on what is directly in front of them, else they cannot pick it up
        ii. washed_plate
            0. only allows player holding below to pick up:
            1. if player holding nothing -> washed_plate
            2. if player holding garnish -> garnish_dish
        iii. garnish
            0. only allows player holding below to pick up:
            1. if player holding nothing -> garnish
            2. if player holding steak_dish -> dish
            3. if player holding washed_plate -> garnish_dish
        iii. garnish_dish
            0. only allows player holding below to pick up:
            1. if player holding nothing -> garnish_dish
        iv. steak_dish
            0. only allows player holding below to pick up:
            1. if player holding nothing -> steak_dish
            2. if player holding garnish -> dish

        Note that we cannot combine steak_dish with garnish_dish into one dish 
            
Players:
Players needs to deliver steak dishes (dish). 
a steak dish needs:
1. washed plate
2. garnish 
3. steak
